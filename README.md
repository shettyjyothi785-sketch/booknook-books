# 📚 BookNook - Books & Stationery

BookNook is a responsive frontend e-commerce website for books and stationery items. It provides users with a warm, cozy and bookish shopping experience.

## 🌟 Features

- 🏠 Home page with hero section
- 📚 Book categories
- 🔎 Search books
- 🔽 Category and price filters
- 📖 Product details
- 🛒 Add to cart
- ➕➖ Quantity adjustment
- 💰 Automatic price calculation
- 💳 Checkout simulation
- 👤 Login/Register simulation
- 📩 Contact form
- 📱 Responsive mobile design
- 💾 LocalStorage cart persistence

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
